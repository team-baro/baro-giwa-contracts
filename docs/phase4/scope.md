# Phase 4 scope

Existing BaroCampaignEscrow, BaroReputationSBT and BQT remain compatible.
New contracts: BaroIndexOracle, BaroAttendance, DojangEligibility and BaroPerformanceEscrow.
The performance escrow pays a channel for a verified user action; it does not replace user quest rewards.

Deliverables: contracts, Foundry tests, calldata preparation, deployment simulation and operations docs.
Product UI, source collection (X/YouTube/Naver), a hosted signer and a daily scheduler are separate integrations.
No live deployment, audit, real-value use, historical index publication or historical attendance is implied.
Source requirements: maintainer-approved Notion Phase 4 draft, reviewed 2026-11-28.
