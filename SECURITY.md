# Security policy

## Supported versions

The latest commit on `main` is the only supported development version until the first tagged
release. No deployment should be treated as production-ready without an independent audit.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Include the affected contract,
impact, reproduction steps, and a suggested fix when possible.

Do not open a public issue or publish exploit details before a fix is available. We will acknowledge
a report within three business days and coordinate disclosure after remediation.
